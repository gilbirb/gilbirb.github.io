## **Internet**
***

### Hardware & Structural Components

**End Systems (Hosts)**: Devices running network applications residing strictly at the network "edge" (e.g., PCs, servers, smart devices).

**Packet Switches**: Intermediary nodes that forward discrete chunks of data (packets); primarily routers (network layer) and switches (link layer).

**Communication Links**: Physical transmission media (fiber, copper wire, coaxial cable, radio, satellite) characterized by their transmission rate or bandwidth (bits per second).

**Networks**: Organized collections of hosts, switches, and links managed under unified administrative domains (e.g., home networks, enterprise networks, regional ISPs, data center networks).

### Protocols & Standards View

The Internet is not a single entity, but a global hierarchy of interconnected Internet Service Providers (ISPs).

**Protocols** strictly define the message format, order, and actions taken during the transmission and receipt of network data (e.g., HTTP, TCP, IP, Ethernet, 802.11 WiFi, 5G).

Governing Standards:
* RFC: Request for Comments
* IETF: Internet Engineering Task Force

### Service & API View

**Distributed Application Platform**: Provides the underlying communication infrastructure supporting end-to-end applications (Web, video streaming, teleconferencing, e-commerce).

**Application Programming Interface (API)**: Exposes network services to software applications (e.g., socket interfaces), allowing end systems to send and receive data across the network core without needing to configure or manage physical link routing directly.
